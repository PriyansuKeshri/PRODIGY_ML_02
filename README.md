# PRODIGY_ML_02  
## Customer Segmentation using K-Means Clustering

This project is part of my **Machine Learning Internship at Prodigy InfoTech**.

The goal of this task is to implement **K-Means clustering** to group retail store customers based on their purchasing behavior.

---

## 📌 Problem Statement

Create a **K-Means clustering algorithm** to group customers based on:

- Annual Income
- Spending Score

This helps businesses identify different types of customers for **better marketing strategies**.

---

## ⚙️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## 📊 Machine Learning Model

**K-Means Clustering**

The model groups customers into different clusters based on similarities in their spending behavior.

---

## 📈 Method Used

### Elbow Method

The **Elbow Method** is used to determine the optimal number of clusters.

It works by plotting:

```
Number of Clusters vs WCSS (Within Cluster Sum of Squares)
```

The "elbow point" represents the best number of clusters.

---

## 📊 Output

The model visualizes different customer groups using scatter plots.

Example clusters may represent:

- High income – high spending
- High income – low spending
- Low income – high spending
- Low income – low spending
- Average customers

---

## 📂 Dataset

Mall Customer Segmentation Dataset

Features used:

- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1–100)

---

## 🚀 Conclusion

K-Means clustering helps businesses better understand customer groups and design **targeted marketing strategies**.
